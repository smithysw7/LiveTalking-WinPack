【快速开始 · 首次使用需联网下载组件】
本包按需下载：仓库本身只有代码（约 20MB），首次运行时自动下载缺失组件
  [env]    内嵌 Python 环境 + PyTorch（约 15GB 下载）
  [llm]    Qwen3.5-9B 本地大模型（约 5.7GB）
  [tts]    Ming-3.0-TTS 语音合成（约 3.8GB）
  [avatar] wav2lip 口型模型 + 数字人形象（约 550MB）
  [asr]    Ming-3.0-ASR 语音识别（约 22GB，★首次语音对话时才下载★）
下载一次后即完全离线可用；不使用语音对话就永远不会下载 22GB 的识别模型。
网络中断重新运行即可断点续传。也可手动控制：
  runtime\python\python.exe setup_components.py status      查看状态
  runtime\python\python.exe setup_components.py download asr 手动预下载识别

1. 双击「启动数字人.bat」
2. 等待启动完成（首次启动模型加载约 1-3 分钟，控制台出现
   "✅ 启动完成" 后会自动打开浏览器）
3. 在打开的页面中点击「开始连接」，数字人出现后
   在聊天输入框输入文字即可对话（大模型回复，数字人开口说话）

【硬件要求】
- NVIDIA 显卡，显存 ≥ 12GB（推荐 RTX 4060Ti / 5060Ti 及以上）
- 内存 ≥ 16GB，硬盘剩余空间 ≥ 30GB
- 需要 NVIDIA 显卡驱动（2024 年后的版本即可）

【两种对话入口】
- 文字对话+数字人播报：dashboard.html（启动自动打开）
- 语音对话（对着麦克风说，数字人听懂后回答）：
  浏览器打开 http://127.0.0.1:8010/webrtcapi-asr.html
  （内置本地语音识别 SenseVoice，无需联网）

【本地大模型（默认，完全离线可用）】
- 模型：Qwen3.5-9B（阿里通义千问最新开源模型，Q4 量化）
- 引擎：llama.cpp（GPU 加速），启动脚本自动拉起，端口 8765
- 无需任何 API Key

【更换为云端大模型（可选，效果更强）】
1. 打开 .env 文件，填入对应厂商的 API Key 并取消注释，如：
   DEEPSEEK_API_KEY=sk-xxxx
2. 打开 config.yaml，将 llm_provider 改为对应名称：
   localllm  → 内置本地大模型（默认）
   dashscope → 阿里云百炼 qwen-plus
   deepseek  → DeepSeek
   zhipu     → 智谱 GLM
   custom    → 任意 OpenAI 兼容接口（需配 LLM_BASE_URL）
3. 重启程序

【语音合成与声音克隆（Ming-3.0-TTS，蚂蚁集团开源，MIT 协议）】
默认使用本地 Ming-3.0-TTS（models/ming-tts/0.5B），支持：
  1. 默认音色：config.yaml 中 REF_FILE 留空即可
  2. 声音克隆：把一段参考音频（wav，10~20秒，安静环境录制的清晰人声）
     放到任意位置，config.yaml 中 REF_FILE 填该文件路径，例如：
       REF_FILE: D:\myvoice\sample.wav
     首次使用自动提取声纹（在原目录生成 sample.wav.spkemb.pt），
     之后数字人全程使用该声音说话。
  3. 官方内置音色：REF_FILE 填音色名（见 Ming-3.0 官方说明）
提示：本地合成的语速约为实时的 80%（每句有 1~3 秒生成延迟）；
  追求绝对流畅可在 config.yaml 中把 tts 改为 edgetts（需联网）。

【语音识别（Ming-3.0-ASR，蚂蚁集团开源，MIT 协议）】
语音对话默认使用 Ming-3.0-ASR（models/ming-asr/asr-tiny，独立进程
运行、不与主程序抢占显存配置）。若显存不足它会自动回退到内置的
SenseVoice 识别。可在 .env 中用 ASR_BACKEND=sensevoice 强制轻量模式。

【自定义人设】
config.yaml 中修改 llm_system_prompt，例如：
  llm_system_prompt: '你是名叫小雅的带货主播，回答热情简短'

【常见问题】
1. 启动时提示端口被占用：
   - 修改 config.yaml 中的 listenport（如 8020）
2. 页面打开后数字人不出现：
   - 确认浏览器允许摄像头/麦克风弹窗（Webrtc 需要 https 或 localhost）
   - 检查防火墙是否放行 8010 端口
3. 大模型没反应：
   - 查看 data/llama-server.log
   - 显存不足时关闭其他占用显存的程序
4. 说话没有声音/口型不动：
   - 确认点击了「开始连接」并成功建立会话（管理后台 admin.html 可查看会话）

【目录结构】
  启动数字人.bat       一键启动入口
  app.py               数字人服务主程序
  config.yaml          全局配置（音色/大模型/端口等）
  .env                 API Key 配置（重命名 .env.example 后生效）
  launcher.py          启动器（自动拉起大模型+服务+浏览器）
  runtime\python       内置 Python 3.12 运行环境（免安装）
  bin\llama            本地大模型引擎 llama.cpp
  models\llm           Qwen3.5-9B 本地大模型权重
  models\qwen3-tts     Qwen3-TTS 语音合成模型
  models\asr           SenseVoice 语音识别模型
  data\avatars         数字人形象（wav2lip256 预处理数据）

【API 对接】
服务启动后提供 HTTP 接口，详见 docs/api.md，
例如驱动数字人说话：
  POST http://127.0.0.1:8010/human
  {"text":"你好","type":"chat","sessionid":"0"}
